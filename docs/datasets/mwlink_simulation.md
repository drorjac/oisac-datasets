# Microwave link simulation dataset

*Simulations and method data* · `mwlink_simulation`

| | |
|---|---|
| Sensor | simulated CML |
| Region | (simulated from a Parsivel disdrometer record) |
| Period | simulation |
| Resolution | as the disdrometer |
| Content | link attenuation simulated from measured drop size distributions for 6-180 GHz, H/V, 0.1-20 km, quantization 0-1 dB |
| Licence | CC BY 4.0 |
| Paper | Pu et al. (2023) |
| Data | [https://doi.org/10.5281/zenodo.7646651](https://doi.org/10.5281/zenodo.7646651) |

## Get it

```bash
python -m oisac_datasets fetch mwlink_simulation            # the small split below
python -m oisac_datasets fetch mwlink_simulation --all      # the whole record
```

Split: the code and the raw disdrometer and weather input (21 MB, 7z); the 175 simulated archives (35 GB) stay remote.
